# 产品方案：回响 Echoes · 灵瑞集特别版

## 1. 核心体验
每天 0 点刷新一个声音命题。用户录下一句话，其他人可以在任意时间点叠录一句回应、环境声、哼唱或 AI 灵瑞旁白，让一句话逐渐生长成多人共创的声音作品。

## 2. 为什么明天还想玩
- **每日限时命题**：命题过期进入回声档案，制造错过成本。
- **盲盒式惊喜**：用户昨晚发出的独白，第二天可能被陌生人叠入吉他、海浪、祝福或灵瑞旁白。
- **声音护照**：主页是一片声音森林，每次参与都会留下声纹叶片、灵瑞图腾和传播路径。
- **情绪养成**：五位灵瑞对应五类人格能量，持续参与会形成专属声纹人格。

## 3. 为什么忍不住分享
- **邀人共创**：分享文案从“听我的作品”变成“我在第 12 秒给你留了个空位”。
- **声音名片**：一键生成可发朋友圈/群聊的声音卡片，强化感性人设。
- **每周声音图腾**：优秀共创会生成灵瑞图腾海报，参与者昵称被刻在作品上。

## 4. AI 功能细节
- **图像生成声音命题**：用户拍摄灵感图，AI 识别颜色、情绪、场景，映射到白泽/麒麟/凤凰/玄鹿/鲲鹏。
- **灵瑞旁白生成**：AI 用守护灵口吻生成 10 秒以内开场白。
- **叠录推荐**：AI 判断作品情绪，推荐“背景音/和声/主角回应”的混音比例。
- **传播摘要**：AI 自动生成一句社交分享文案。

## 5. Hackathon MVP 范围
- Web 前端 + Node 后端。
- 每日命题、图像命题、录音/模拟音频、作品列表、叠录、声音护照、分享卡片。
- 后续可接入真实 ASR/TTS/图像理解/音频混音模型。

## 6. 商业与增长
- 面向音乐、播客、情绪疗愈、校园社交和城市文化活动。
- 可做品牌命题、城市声音地图、节日共创、艺人粉丝合唱。
