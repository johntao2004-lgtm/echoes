# 3 分钟 Demo 讲稿

大家好，我们的作品叫「回响 Echoes」。它解决的是一个问题：为什么今天的社交平台越来越像展示橱窗，而不是共同创作的现场？

第一步，用户进入页面，会看到今日限时声音命题。例如“给 3 点还醒着的人留一句话”。这让用户每天都有一个回来看的理由。

第二步，用户可以上传一张图。AI 会把图片里的场景和情绪映射成灵瑞守护灵，比如白泽代表洞察、凤凰代表重生，并生成新的声音命题。这一步对应多模态交互：图像是输入，声音是表达，文本是引导。

第三步，用户录下一句话，发布为声音种子。其他人不是点赞完就走，而是可以选择某一秒叠录回应。滑竿决定自己是背景音、和声还是主角。

第四步，所有参与都会沉淀到声音护照。你的主页不是作品列表，而是一片不断生长的声音森林。每周优秀共创会生成声音图腾，参与者昵称会被刻在作品上。

我们希望回响成为一个每天都会回来查看“我那滴水又引起什么涟漪”的地方。
