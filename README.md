# 回响 Echoes · 灵瑞集 AI 声音共创 Demo

一句话：每天一个声音命题，用户录一句话，其他人可在任意一秒叠录回应，共同把一句话变成不断生长的声音作品。

## 已实现功能
- 每日限时声音命题与今日守护灵。
- 图像/图片描述生成灵瑞命题：满足“图像作为核心输入，可结合语音/文本”的互动方向。
- 浏览器录音：允许麦克风时真实录音，不允许时生成模拟回响音频，保证现场可演示。
- 作品发布、叠录回应、混音滑竿、作品涟漪条可视化。
- 声音护照、灵瑞图腾、声音名片 Canvas。
- 零依赖 Node.js 后端，数据写入 `data/db.json`。

## 运行
```bash
cd nanjing-hackathon
npm start
```
打开：<http://localhost:5173>

## 黑客松主题适配
1. **赛道一：AI 交互 / 创意产品**  
   页面可直接体验从命题、录音、叠录到分享的完整闭环。
2. **赛道四：多模态互动应用**  
   以图像或图片描述作为核心输入，生成灵瑞声音命题，再结合语音录制与文本旁白。
3. **灵瑞集特别赛道**  
   将白泽、麒麟、凤凰、玄鹿、鲲鹏作为声音守护灵，建立“灵瑞声纹护照”和“每周声音图腾”。

## 路演建议
- 先展示“今日命题”，强调每日回访。
- 上传/描述一张图片，生成灵瑞命题，体现 AI 能力。
- 录一句声音或使用模拟音频，发布声音种子。
- 选择已有作品，调节滑竿叠录回应。
- 生成声音名片，讲“分享的是第 12 秒空位，而不是普通链接”。
